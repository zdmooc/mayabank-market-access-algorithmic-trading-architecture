# Synthetic Evidence

This directory contains executable evidence for the Market Access lab.

Current evidence classes:
- functional/state-machine tests;
- sequence-gap/replay tests;
- selective kill and stale-data tests;
- synthetic latency benchmark.

Rules:
- synthetic benchmark numbers are not production latency claims;
- CI success proves only this repository's synthetic executable baseline;
- venue certification, direct exchange connectivity, production multicast and HFT remain NOT_PROVEN.
